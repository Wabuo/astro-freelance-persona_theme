Fixes the Expressive Code copy button in two ways. On hover-capable devices the theme's `scale(0.55)` de-emphasis transform was global although it was tuned against the touch-layout geometry only: EC pairs `@media (hover: hover)` with its narrow 2rem hover-revealed button, and the theme's responsive root font size (<16px on large screens) shrinks that rem further, so desktop buttons rendered as ~12px specks instead of their native EC sizing. The shrink is now scoped to `@media (hover: none)` — mirroring EC's own interaction discrimination (including non-hover desktop-sized devices like landscape tablets/kiosks, which permanently show the full 2.5rem button in the reading flow) — so touch layouts keep their shipped look exactly while desktop gets the native ~21px hover-revealed button. Separately, the button's outline ring in dark mode was as opaque as in light (60%, a light-mode dial that the dark cases only overrode for color, not opacity) and read too bright on dark code backgrounds; the dark cases now dial the outline down to 30% via a `--copy-btn-outline-opa-dark` variable in both dark scenarios (OS-dark with untouched chooser, and forced dark).
